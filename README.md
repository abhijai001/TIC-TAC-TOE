# Tic Tac Toe

A simple, interactive Tic Tac Toe game built with **HTML, CSS, and JavaScript** as part of my JavaScript learning journey.

This project focuses on applying core JavaScript concepts to a practical browser-based application, including DOM manipulation, event handling, game logic, and dynamically updating the user interface.

## Overview

Tic Tac Toe is a two-player game played on a 3×3 grid. Players take turns placing their respective marks on the board, with the goal of getting three marks in a row horizontally, vertically, or diagonally.

The project was built to strengthen my understanding of how JavaScript can interact with HTML elements and control the behavior of a web page.

## Features

- Interactive Tic Tac Toe game board
- Two-player gameplay
- Turn-based game logic
- Win-condition detection
- Draw/tie detection
- Dynamic UI updates using JavaScript
- Clean and simple interface

## Tech Stack

- **HTML5** – Structure and game layout
- **CSS3** – Styling and visual presentation
- **JavaScript (ES6+)** – Game logic, DOM manipulation, and event handling
